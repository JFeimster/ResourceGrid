# ResourceGrid App

Next.js App Router UI for browsing ResourceGrid.

Initial responsibilities:
- registry health and counts
- resource/content discovery
- relationship browsing
- source/provenance visibility
- duplicate/stale/reconciliation diagnostics

Future routes:
`/resources`, `/content`, `/relationships`, `/sources`, `/clusters`, `/gaps`, `/duplicates`, `/resource/[id]`

The app reads canonical registries and compiled outputs. It is not a second source of truth.
