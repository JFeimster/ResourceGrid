# Credit Report Analysis

## Overview
Use this skill to interpret bureau data and turn it into plain-English findings. Prioritize account status, payment history, utilization, derogatories, inquiries, public records, and identity mismatches.

## Workflow

1. Identify the source and bureau if known.
2. Extract the account-level details:
   - Trade line name
   - Status
   - Payment history
   - Credit limit or balance
   - Date opened
   - Last reported date
   - Public remarks or notes
3. Summarize findings in this order:
   - Positive signals
   - Negative signals
   - Inconsistencies or missing data
   - Most likely approval impacts
4. Translate each issue into one concrete next action.
5. If the report text is incomplete, state what is missing instead of guessing.
