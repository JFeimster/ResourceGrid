# Credit Score Improvement

## Overview
Use this skill to turn a credit weakness into a prioritized improvement plan. Keep advice realistic, time-bound, and tied to the specific profile issue.

## Workflow

1. Identify the limiting factor:
   - Thin file
   - Late payments
   - High utilization
   - Missing trade lines
   - Inconsistent business identity
   - Too few reporting accounts
2. Separate fixes into:
   - Immediate damage control
   - 30-day actions
   - 60-90 day actions
   - Longer-term growth actions
3. Recommend the highest-leverage behavior changes first.
4. Explain expected impact in plain language, without promising exact score movement.
5. If the user asks for a plan, return a checklist with owner, timing, and success metric for each item.
